DJGABO ENGINE

Política de privacidad

Esta política explica cómo DJGABO Engine trata la información cuando se conecta con Google y YouTube mediante OAuth.

Información de la aplicaciónCondiciones del servicio

1. Datos a los que puede acceder la aplicación

Cuando un propietario autoriza un canal, Google puede proporcionar credenciales OAuth y datos necesarios para identificar y operar el canal autorizado. La aplicación puede acceder a información de YouTube necesaria para publicar, consultar, modificar o eliminar videos según las funciones solicitadas por el propietario.

2. Uso de los datos

Los datos obtenidos mediante las API de Google se utilizan exclusivamente para ejecutar las funciones de DJGABO Engine: autenticar los canales conectados, publicar videos, consultar su estado y realizar las acciones que el propietario solicita desde el panel.

3. Almacenamiento y protección

Las credenciales OAuth se almacenan en la infraestructura privada del servicio y se protegen mediante cifrado y controles de acceso. No se publican ni se incluyen en el código fuente del proyecto.

4. Compartición de datos

DJGABO Engine no vende datos de usuarios ni credenciales de Google. Los datos no se comparten con terceros salvo cuando sea técnicamente necesario para prestar la función solicitada, cumplir obligaciones legales o proteger la seguridad del servicio.

5. Conservación y eliminación

Las credenciales y datos operativos se conservan mientras sean necesarios para mantener la conexión y el funcionamiento del servicio. El propietario puede revocar el acceso desde su cuenta de Google y puede solicitar la eliminación de los datos almacenados relacionados con la autorización.

6. Revocación del acceso

El acceso de DJGABO Engine puede revocarse en cualquier momento desde la configuración de seguridad de la cuenta de Google. Después de una revocación, la aplicación dejará de poder utilizar esa autorización.

7. Uso de información recibida de Google

El uso y transferencia a cualquier otra aplicación de la información recibida de las API de Google se ajustará a la Google API Services User Data Policy, incluidos sus requisitos de uso limitado.

8. Contacto

Para consultas sobre esta política, revocación, acceso o eliminación de datos, utiliza el correo de contacto del desarrollador mostrado en la pantalla de consentimiento OAuth de DJGABO Engine.
